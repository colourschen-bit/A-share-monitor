- 旧EPS模型的12%半年折现保留作估值压力余量，不保证半年退出或12%年化；没有明确目标日不显示远期收益。压力价不是底价或最大回撤。
- OCF不等于FCFE；合并现金不等于归母现金；扣少数已付股息后仍有少数留存权益。利息、租赁、金融子公司及受限资金须一致处理；不重复扣现金流表已含项目。
