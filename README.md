## 定价与执行

个股盈利情景=正常化EPS×倍数＋显式加值；EPS条件区=假设估值÷(1+12%)^0.5×(1−安全边际)，并不保证实际年化回报。招行、财险及新增三家银行PB已为现值，直接乘安全边际，不重复折半年。3–6个月是催化核验窗口，盈利参照为正常化全年/未来12个月。

ETF区间=固定复核净值×[Σ(前十持仓权重×假设折价比例)＋剩余净资产权重×假设比例]。剩余净资产包括现金、应收和负债净额，统一折价只是近似。中间情景由区间上沿÷90%反推，不能作为独立公允价值交叉验证。净值锚不随日常行情机械平移。

不分配未经验证的情景概率，不宣称统计胜率。压力价不是底价或最大回撤；撤掉原机械折价形成的“极端错杀区”。

15%现金是建满后的最低目标；等待时可持有更多现金。首笔不超过单只目标的1/3，每周新增股票金额不超过组合4%，均为执行约束假设。目标权重不代表立即交易。

## 口径与时效

- 核心卡片与候选区以交易币种显示，完整估值表统一人民币。港股按SAFE 2026-10-14的0.85688人民币/港元折算，不是实时成交汇率。
- 每项显示自身行情时间，失败保留有日期的历史快照；新增没有报价时不制造快照。
- 价格判断为有折价、接近估值、有溢价、暂不估值。经营成立条件单独记录；无效日期、缺行情、论点失效或模型过期均不会显示建仓达标。
- 行情刷新不更新财报、估值假设或未来条件。公司分红、转增、融资、新财报和指数调仓后应重估。
- OCF不等于FCF，合并现金不等于归母现金，保险保费现金不等于自由现金；银行不用工业企业OCF/利润比例评价。
- 盈利驱动分散不是保证负相关的对冲。85%股票同时跌30%时，组合约跌25.5%，15只不保证低回撤。
