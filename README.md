## 计算口径
EPS/BPS/FCFE为未来12个月或正常化的研究假设；3–6个月是催化评价窗口，不是将半年的利润直接乘PE。
EPS/营运EPS/BPS × 倍数，或每股FCFE ÷ 要求收益率 + 投资折价值。
主观情景加权并非统计胜率。
条件关注区 = 加权情景价 / (1+12%)^0.5 × (1−个性化安全边际)。
12%年化要求回报、半年折现及安全边际都是显式主观输入。
情景收益不含分红、税费或交易成本，压力情景不等于最大回撤/VaR。
所有事实与参数应在新财报、再融资、除权分红、行业政策变化后复核。
