## 计算口径
EPS/BPS/FCFE为未来12个月或正常化的研究假设；3–6个月是催化评价窗口，不是将半年的利润直接乘PE。
个股使用EPS/营运EPS/BPS × 倍数，或每股FCFE ÷ 要求收益率 + 投资折价值；ETF使用锚定净值 × 合理指数估值 / 当前指数估值 × 基本面系数。
不使用未经验证的情景概率，以基准情景作为价格参照，压力/修复情景作为敏感性边界。
条件关注区 = 基准情景价 / (1+12%)^0.5 × (1−个性化安全边际)。
12%年化要求回报、半年折现及安全边际都是显式主观输入。
情景收益不含分红、税费或交易成本，压力情景不等于最大回撤/VaR。
所有事实与参数应在新财报、再融资、除权分红、行业政策变化后复核。

## 行情与币种
价格判断固定为四种：有折价（价格≤关注区上沿）、接近估值（关注区上沿<价格≤基准情景价）、有溢价（价格>基准情景价）、暂不估值（无模型、行情无效/过时、模型过期或论点失效）。低于关注区下沿仍为有折价，但提示遗漏风险。价格分类不等于交易建议。筛选“有折价”遵循相同有效性检查。
腾讯行情可能延迟；每项显示自身时间戳。刷新失败时明确保留历史快照，不能宣称实时。
港股显示HKD原价，并用SAFE 2026-10-14的0.85688人民币/港元中间价比较人民币估值，汇率不是实时成交汇率。
行情刷新不会自动更新财报、估值假设或条件验证。
